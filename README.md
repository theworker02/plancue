# plancue

Plan CSV/TSV cue tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/plancue/

## Install / run

```bash
git clone https://github.com/theworker02/plancue.git
cd plancue
node src/cli.js
node --test
```
